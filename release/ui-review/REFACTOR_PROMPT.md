# 远程 UI 重构提示词

重构 ConeAI 的 ConeCode 远程界面，以 ConeCode 当前界面为视觉基准，先逐区域截图审查，再修改。

保留 Chat、Work、RSI 三个独立组件；Work 模式仅保留 Standard、Goal。清理重复导航和重复控件。远程屏幕使用已接入的 UU 远程方案。

重点检查侧栏与内容区比例、标题栏高度、标签条密度、字体层级、按钮尺寸、图标与文字中线、输入栏边距、弹窗和键盘遮挡。不要等比例缩小桌面布局；手机和折叠外屏使用紧凑布局，Pad 和展开屏使用常驻侧栏，保持相同的视觉语言。

覆盖 Chat、Work、RSI、会话抽屉、模式菜单、模型选择、变更审批、文件浏览与编辑、终端、输入栏和 UU 远程入口。只截图和操作目标应用，逐项记录问题；修改后用同尺寸截图对照，并验证功能、字体缩放和深色模式。

不以构建通过代替视觉验收，不把自动化定位失败直接当作产品缺陷。记录真实设备与模拟窗口的区别，并明确第三方登录和真实远控尚未验证的边界。
